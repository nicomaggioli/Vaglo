# Brand and asset notes

## Direction

The user supplied `Branding Ophelia.pdf` and https://www.ophelias.ai/ as visual references. The direction draws on the reference's black, white, bright mint, botanical imagery, and straightforward sans-serif typography. The site design, copy, names, and vector symbols were created for this project. No Ophelia logo or website photography was copied into the site.

Palette: Obsidian `#0B0D11`, mint `#65FC9F`, white `#FFFFFF`, and ash `#BDBDBD`. Geist and Inter are bundled with their SIL Open Font Licenses.

The working Ellery identity uses an original pair of overlapping leaves and a vector wordmark derived from Geist at weight 450. Vector logos are self-contained and do not require a font to render. Alternative Bracken and Avenell symbols remain in the direction study.

## Original image generation

Generated with the built-in image generation tool on 2026-09-13, then copied into this repository and compressed as WebP.

- `ellery-canopy.webp`: original editorial botanical image. Direction: medium-format film feel, rich green leaves and soft leaf shadows, translucent mint light, subtle grain, deep green negative space at left. No text, logo, UI, or CGI styling.
- `ellery-architecture.webp`: original editorial architecture image. Direction: a quiet modernist concrete walkway, lush landscape, dappled tree shadows, subtle grain, natural daylight, eye-level perspective. No people, signage, or text. This is atmospheric generated imagery, not a claimed customer project.

The exact generated source PNGs remain in the local Codex generated-images folder. WebP derivatives included here are the deployable assets.

## Product imagery

All `demo-*.webp` and `demo-stills/*.webp` assets were captured from the supplied dashboard frontend running with synthetic fixtures and the working brand. These are actual interface layouts with fictional demonstration records, not real customer results. The private application source is intentionally excluded from this website repository.
